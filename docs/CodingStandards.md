# Coding Standards

## General

Write clean, maintainable code.

Avoid duplication.

Keep components small.

Prefer composition over inheritance.

---

## Naming

PascalCase

Components

camelCase

Variables

UPPER_CASE

Constants

---

## Components

Maximum responsibility:

One feature.

Avoid components larger than 300 lines when possible.

---

## Forms

Every input requires validation.

Character limits are mandatory.

Meaningful error messages must be displayed.

---

## Tables

Every table supports

Search

Sorting

Filtering

Pagination

---

## Performance

Use lazy loading.

Avoid unnecessary renders.

Reuse shared components.

Avoid duplicated logic.

---

## Responsive

Desktop

Tablet

Mobile

must all be supported.
